How Orch works

Orch keeps your files in order, then gives you simple places to review files, follow up on work, keep projects together, and draft updates when you need them.

1. Sorting your files

  • Orch watches your Downloads folder (set in Settings). New files there get sorted automatically, mostly by whichever profile is active.
  • Not sure where something belongs? It's never lost: unclear files wait in Files to check so you can approve, redirect, or ignore them.
  • Wrong guess? Every row in Recent Moves has a Move button, and Undo reverses any move. Folder Rules let you teach Orch your own routing without writing anything technical.
  • Already have a messy folder from before Orch? Folder Imports looks through it and suggests subjects and rules, only touching anything once you say yes.

2. Learning from what is sorted

  • Learning turns your sorted files into topics, things worth revisiting, and a review queue so nothing gets forgotten.
  • Resource Radar finds real videos, books, and repos for saved topics, never a made-up link. Any file can get a summary if writing help is turned on.

3. Projects and proof

  • Projects tracks what you're building from idea to finished, turning it into proof you can reuse later.
  • Write about your work as a draft, then publish it to GitHub or your own site only when you choose to.

4. Staying connected

  • Connections shows what's available and what's already set up for this profile: MUELE, timetable, backups, GitHub, and publishing.
  • Orch never stores a password for any of these. It always uses the service's own official sign-in, and you can disconnect at any time.

5. Staying on top of things

  • Notifications keeps a record of deadlines and sync results, even ones you missed. Memory shows the sorting rules Orch has learned from your own corrections, so nothing it does is a black box.

Create or switch profiles from Profiles. Change watched folders and other setup from Settings.
