What Orch can do

Features built around how your files and work actually happen.

Orch starts with files, then connects the rest of your work around them: classes, deadlines, revision, projects, career proof, and the small decisions you should still control yourself.

Organize files

Downloads becomes an organized folder, not a pile of loose files

Orch watches the folders you choose and helps keep incoming files from turning into a long, unnamed pile.

Watched folders

Choose the Downloads folder or another folder where files usually land. Orch watches that place and reacts when new files appear.

Profiles for different work

Use one profile for school, another for online courses, research, work training, or any folder life you want kept separate.

Smart file sorting

Course codes, familiar names, file types, and your own rules help Orch place notes, assignments, past papers, installers, archives, and reports.

Decision Inbox

Files that look sensitive, unclear, or hard to place wait for review. You can approve, move somewhere else, ignore, or clear them.

Undo recent moves

Every move leaves a record. If Orch sends something to the wrong place, you can restore one file or undo a recent batch.

Rules and memory

Create your own routing rules, remember good decisions, and see which folders Orch uses most often over time.

Makerere University support

Your course structure connects directly to your files

Makerere University students can set up college, school, programme, MUELE, and timetable details once, then let them guide how files and dates are organized.

Makerere University guided setup

Makerere University students can start with college, school, programme, year, semester, and course units instead of typing the whole structure by hand.

MUELE course sync

Connect MUELE to manage enrolled courses, download materials, and track assignment dates inside Orch.

Class timetable

Connect a Makerere University timetable group, then see lectures, tests, and exams when the timetable has them. You can also add your own entries.

Study and deadlines

Course work, deadlines, and revision stay connected to your files

Sorted files build context over time, so deadlines and study tools can point back to the subjects and documents you already have.

Assignment tracker

Keep MUELE deadlines and manually added assignments in one place, with checklists, status, and evidence paths.

Exam countdown

See days left per paper, open assignments, and review coverage so exam pressure is easier to read early.

Notifications record

Deadline warnings, MUELE sync updates, and missed popups stay in a permanent list until you clear them.

Subject memory

Each subject or course can collect files, summaries, topics, assignments, reviews, and an activity timeline.

Review queue

Schedule review items from study materials, mark them done, skip them, and let due work rise to the top.

Past paper review

Use past papers to find repeated topics, weak areas, and questions worth turning into flashcards.

Flashcards

Create cards from past paper questions or from useful headings and definitions found in summaries.

Weakness radar

See subjects that are going quiet, weak areas already flagged, and files that still have no review scheduled.

Study timetable

Build a study plan from classes, assignments, exams, weak areas, reviews, and past paper work.

Resource radar

Find follow-up reading or videos based on subject memory, themes, weak areas, and recent files.

Study exports

Export a profile or one subject as a bundle with files, summaries, folder map, reading list, and a study guide PDF.

Grade targets

Set coursework, test, and exam weights so you can see what score you still need to reach your target.

Projects and career records

Projects and proof stay available after submission

Orch also has a career side for keeping useful evidence, drafts, and publishing steps close to the work itself.

Project Studio

Track projects by status, problem, stack, GitHub link, folder path, lessons learned, and portfolio notes.

Project updates

Keep short notes about what changed, what you built, and what proof belongs with the project.

Career digest

Turn recent project work and learning into a simple weekly record, so progress is easier to explain later.

Content drafts

Draft project updates, course reflections, or portfolio posts, then approve, polish, export, or mark them posted.

Publishing channels

Connect a website or GitHub repo for posts. Orch keeps drafts for review, and publishing happens only when you click.

Optional tools

Helpful tools stay optional

Orch includes summaries, course guides, backups, publishing, and recommendations, but you can start with simple file organization.

Optional backups

If you connect Google Drive, Orch can copy sorted files to an Orch Backups folder in your own Drive.

Summaries when you ask

Summarize a sorted file, open the summary again, or download it as a PDF when writing help is enabled.

Course guides

Generate a guide for a course and keep it available beside the subject files it belongs to.

Command search

Jump to pages, files, or summaries from one search box instead of hunting through menus.

Clear history controls

Recently moved items, inbox rows, and notifications can be cleared one by one or in groups where the app supports it.

Folder browser

Pick watched folders, project folders, backup folders, and evidence folders from inside the app.

Support message

There is a contact path inside the app for questions, bugs, and feedback when something does not behave as expected.

Start with what you need

You do not have to use everything on day one.

Begin with watched folders and safe sorting. Add MUELE, timetables, revision tools, project tracking, backups, or publishing when they match your work.
