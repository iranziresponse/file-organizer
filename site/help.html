Help notes

Use Orch with confidence.

These notes cover the main parts of the app: setup, sorting, review, deadlines, study tools, projects, and support.

First setup

Start by creating a profile. A profile keeps one kind of work separate, such as school, online learning, research, work training, or projects.

  • Makerere University students can use the guided setup.
  • Other users can make their own labels and subjects.
  • Choose the folder Orch should watch for new files.

When files arrive

Orch checks new files from the folders you choose. It looks at names, course codes, file types, and rules you have saved.

  • Clear matches can be sorted for you.
  • Unclear files wait for your review.
  • Every move leaves a record.

Decision Inbox

This is where Orch places files that need your decision. You can approve the suggestion, choose another folder, ignore the file, or clear the row.

Recent Moves and Undo

Use Recent Moves to see what changed. If a file went to the wrong place, you can undo the move or choose a better folder.

Settings

Settings is where you change watched folders, extra folders, sorting behavior, and optional helpers. If Orch says something needs setup, start with Settings or the setup checklist.

Profiles

Use profiles to keep different work separate. One profile can be for school, another for research, and another for a project or online course.

School and study

Use the study pages when files need context

Sorting is only the start. Orch also provides pages for subjects, reviews, assignments, exams, and study plans.

Subjects

Each subject can collect files, summaries, topics, assignments, resources, and review items.

Reviews

Create review items from files or topics, then mark them complete as you revise.

Assignments and exams

Track deadlines, add your own dates, and see what is coming up before it becomes urgent.

MUELE

Makerere University students can connect MUELE to bring course files and assignment dates into Orch.

Timetable

Use your timetable group when available, or add your own class, test, or exam entries.

Exports

When you need a copy of one subject or profile, export a bundle with the related files and notes.

Projects and career records

Project Studio is for work you may want to present later. Add the project name, the problem it solves, links, folder path, lessons learned, and updates. Orch can help turn that work into a weekly record or draft post when you choose.

When something needs attention

  • Check the setup checklist if Orch says a feature is not ready.
  • Look at Recent Moves if a file is missing.
  • Use Decision Inbox if Orch is waiting for your choice.
  • Use Support if a course, page, or action still needs review.
